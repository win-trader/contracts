# Notification channel contract stays a comment-discipline mirror

The Postgres `LISTEN/NOTIFY` channel contract is defined in TypeScript in `@win-trader/data` (`notifications.ts`: `CHANNELS` + `ChannelPayloads`) and mirrored by the trigger DDL in the migration `0004_notification_triggers.sql`, which independently hardcodes the same channel-name strings and `json_build_object` payload keys. The two sides are kept in sync by a comment and caught in code review — not by a build-time guard or codegen. The architecturally cleaner alternative was a `check-notify-mirror.mjs` script (modelled on the existing `check-worker-safe.mjs`) that parses the trigger DDL and asserts the channel names and payload-key sets match the TS registry, or going further and generating the trigger DDL from the registry outright.

We rejected those options at the current surface size. After the Bun SSE transport was removed (the app's `broadcaster.ts` and its test, which re-hardcoded the channel strings, were deleted), the contract has exactly two representations — the TS registry and the SQL triggers — both owned by `@win-trader/data` and single-sourced in one migration file. The shared surface is five channels that change a handful of times a year, which is the same low-drift, small-surface regime ADR-0004 invokes to keep the constants mirror on comment discipline. Codegen specifically would require expanding `ChannelPayloads` into a full trigger spec (table, which DML ops fire, `OLD` vs `NEW`, key columns) that the type does not hold today; a parsing guard is cheaper but still adds a CI surface for a mirror that rarely moves. We note one asymmetry against ADR-0004: a constants drift is a loud, irreversible break, whereas a channel-payload drift fails *silently* (a renamed channel never fires; a re-fetch key reads back `undefined`) — that is the single strongest argument for a guard, and we accept the silent-failure risk at five channels. Revisit when the channel set grows past ~10, when a payload's non-key fields become load-bearing on the wire for more than the one passthrough channel (`positions`), or the first time a silent drift actually reaches production — at which point the `check-notify-mirror.mjs` guard (not codegen) earns its CI cost.

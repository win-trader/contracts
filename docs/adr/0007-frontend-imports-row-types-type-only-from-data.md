# Frontend imports row types type-only from worker-safe @win-trader/data

The frontend derives its API-response row shapes by importing the Drizzle-inferred types from `@win-trader/data` with `import type` — the same package the API's read store infers from (`MarketRow = typeof markets.$inferSelect`) — rather than hand-redeclaring them in `frontend/src/api/types.ts`. This reverses an earlier in-code decision recorded in that file's header ("Defined here, not imported from `@win-trader/data`, to keep the frontend bundle free of pg/drizzle"). That concern is real for *value* imports but does not apply to type-only imports: `import type` is erased by the bundler, so no `import` statement survives and no `pg`/`drizzle` runtime reaches the browser. `@win-trader/data` is additionally worker-safe (`check-worker-safe.mjs` bans `pg`/`node:`), so even an accidental value import would at worst pull bundleable `drizzle-orm` types, never `pg`.

Hand-redeclaration was rejected because it kept a second, hand-maintained copy of the schema contract with no compile-time link to it — additive schema changes drifted silently, and test fixtures that hand-build full row literals lied (compiled clean against a stale shape) rather than failing. Computed/aggregate response shapes that are not table rows (leaderboard, profitability, candles) live in a pg-free `responses` types module in `@win-trader/data` and are annotated onto the read store's raw-SQL query results, so the API and the frontend share one definition of those too. The frontend's `types.ts` retains only genuinely frontend-shaped types (the SSE event envelopes). We deliberately did not add an enforcement guard (an ESLint `consistent-type-imports` rule, or a check that all frontend imports from `@win-trader/data` are type-only) — `import type` discipline plus the worker-safe guarantee is sufficient at the current size. Revisit when the frontend needs a runtime *value* from `@win-trader/data` (forcing a value import), at which point either that value moves to a dedicated browser-safe entry or the type-only guarantee gets the enforcement guard.
